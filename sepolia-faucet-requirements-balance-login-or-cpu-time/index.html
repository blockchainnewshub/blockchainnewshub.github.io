Sepolia Faucet Requirements: Balance, Login or CPU Time

Sepolia faucet requirements compared: provider faucets may ask for mainnet ETH or an account, while proof of work trades browser mining time for test ETH.

By Crypto Docket NewsroomNov 27, 2026 · 12:42 UTC#567c694 min read

Sepolia faucets usually ask for either mainnet ETH, an account login or browser mining time; each requirement filters automated claims. Alchemy’s faucet documentation describes eligibility checks and request limits that vary by network. The choice comes down to what you can provide: a funded mainnet address, an account, or spare CPU time.

Why do Sepolia faucets ask for mainnet ETH?

A balance-gated faucet checks that the receiving address already holds ETH on Ethereum mainnet before sending test ETH. That can make claiming quick, but it rules out a freshly created wallet with no mainnet funds.

The mainnet balance is an anti-bot filter: it asks claimants to meet a condition tied to an existing address. The faucet checks the address you enter, so ETH held by another wallet you control may not count. Treat the provider’s own eligibility instructions as decisive.

Thresholds, request limits and daily amounts are set by each provider and can change. A balance requirement that works for one faucet does not describe every provider. Check the current terms before choosing, especially if your wallet is new or its mainnet balance is low.

What does a Sepolia proof-of-work faucet require?

A proof-of-work faucet asks your browser to mine hashes, then gives you a claim step; it requires CPU time instead of mainnet funds or an account. pk910’s Sepolia PoW faucet mines in the browser tab, making it an option for an empty fresh wallet.

The trade-off is time and processing power. Keep the faucet tab running while it mines, then claim when you are ready. The reward grows with mining time, so leaving the tab running longer before claiming can yield more test ETH without first funding the address on mainnet.

That makes PoW useful when you can spare the computer time and want to avoid an identity or balance gate. It is less convenient when you need test ETH immediately, or when running browser mining is a poor fit for your device or workload. The faucet’s claim step still matters: mining and receiving the funds are separate parts of the process.

Which Sepolia faucets require an account login?

A login-gated faucet ties claims to an account identity and limits how often that identity can request tokens. Google Cloud’s Web3 faucet, for example, applies rate limits to each Google Account and wallet address; the exact limit depends on the network.

Logging in can be simpler than proving a mainnet balance or waiting through browser mining, but it means using an account and working within its claim period. A login requirement is an anti-abuse filter too: it limits repeated requests by account as well as address. Check the provider’s current page for its request rules, since amounts and limits can change.

How do I add Sepolia to MetaMask?

Add Sepolia as a network so the wallet can display and use the test ETH you receive. Sepolia’s chain ID is 11155111; matching that ID helps distinguish the test network from Ethereum mainnet.

chainlist.org is a concrete example of an EVM network directory whose chain ID information helps you select the right network. Use Chainlist to find Sepolia by chain ID 11155111 and add it to the wallet. Then switch MetaMask to Sepolia and check the same receiving address that you gave the faucet.

Say a developer has a fresh wallet before claiming: the address is set up, but MetaMask is showing mainnet and no Sepolia test ETH. After adding Sepolia through Chainlist and receiving a faucet transfer, that same address can show a Sepolia balance when the wallet is switched to the Sepolia network. The address stayed the same; the selected network and its displayed balance changed.

Which Sepolia faucet requirement should I choose?

Choose by the condition you can meet: use a balance-gated faucet if the receiving address already has mainnet ETH, a login-gated faucet if you are comfortable using its account, or a PoW faucet if you have spare CPU time and want to start with a fresh wallet.

For a funded mainnet address, a balance check may offer the most direct claim. For an empty wallet, browser mining avoids the balance condition, with longer mining time potentially producing a larger reward. A login can suit someone who already has the relevant account and accepts its claim limits. Before you start, check the faucet’s current requirements; once the transfer arrives, switch the wallet to Sepolia to use it.
