MetaMask Says Wrong Network on Polygon Portal: Choose the Right Chain

When MetaMask says wrong network on Polygon Portal, its selected chain differs from the current step; switch to Ethereum or Polygon PoS, then retry safely.

By Crypto Docket NewsroomNov 27, 2026 · 03:33 UTC#215f444 min read

MetaMask shows “wrong network” on Polygon Portal when the selected network differs from the one required for the current action, so switch to the network named by the Portal prompt and retry.

The required network can change during a transfer. A Polygon bridge transfer between Ethereum and Polygon PoS can involve actions on both networks, so the right choice depends on whether you are approving, depositing, starting a withdrawal, or claiming it. Our Polygon bridge connection fixes article covers wallet connection trouble; the network question here is which chain the current Portal step needs.

Why does MetaMask say the wrong network on Polygon Portal?

MetaMask reports the network it currently has selected, while Polygon Portal needs the network for the transaction you are trying to submit. Ethereum and Polygon PoS are separate networks, and MetaMask must be on the transaction’s network to submit it.

That means a wallet can be connected and still be on the wrong network for the next step. The message is about the chain selected for that action, not a general verdict on the whole transfer. Read the network named in the Portal prompt and compare it with MetaMask’s network selector.

Consider a withdrawal: you start it on Polygon PoS, then later claim the assets on Ethereum. If you expect the claim to use Polygon PoS because that is where the withdrawal began, MetaMask’s Ethereum prompt can look wrong. The claim is a separate step and may require Ethereum.

What network should MetaMask use for Polygon Portal?

Use the network named for the current transfer step: deposits usually start on Ethereum, a withdrawal burn starts on Polygon PoS, and the final withdrawal claim is on Ethereum.

For a deposit, check the Portal prompt before approving or submitting. The deposit usually begins on Ethereum, so MetaMask may need to be on Ethereum for that action. An approval and the deposit are distinct actions; follow the network requested for each one rather than assuming every prompt in the transfer will use the same chain.

For a withdrawal, the starting burn is on Polygon PoS. Once that process reaches the claim step, the required network is Ethereum. The change between chains is part of the route: the network for the claim is determined by the claim action, not by where you initiated the withdrawal.

Polygon PoS has chain ID 137, also written as 0x89. Use the chain name in the Portal prompt and MetaMask selector to identify the network; the chain ID helps confirm that a Polygon PoS entry is the intended one.

How do I switch networks and retry the Portal action?

Switch MetaMask to the network named in the Portal prompt, then retry that action in Polygon Portal.

Use MetaMask’s network selector, or accept the network switch request shown by the Portal wallet prompt. Check the selected network again after switching, return to the same Portal step, and retry. If the prompt asks you to approve or submit a transaction, read its details before confirming.

Keep track of the stage you are on. If you completed a withdrawal burn on Polygon PoS and are now claiming, switch to Ethereum for the claim when Portal requests it. Switching networks does not mean restarting the transfer; it changes the chain MetaMask is set to use for the next action.

How do I add Polygon PoS to MetaMask?

If Polygon PoS is missing from MetaMask’s network selector, add it using the network details in Polygon’s official documentation, including chain ID 137 (0x89).

Compare the network details with Polygon’s official source before saving them. Then select Polygon PoS in MetaMask and return to the Portal step that requested it. Avoid using network settings copied from an unsolicited message or an unfamiliar site; an incorrect entry can send you to a different network than the one the prompt requires.

What should I check if the wrong-network message remains?

Recheck the Portal step, the network it names, and the network currently selected in MetaMask; they should match before you retry.

A prompt can change as you move from approval to deposit, or from withdrawal burn to claim. Read the latest prompt rather than relying on the network used earlier. If the network names already match, reconnecting the wallet may help with a separate connection issue, but first confirm which action Portal is asking you to take.

  • Match MetaMask’s selected network to the current Portal action.
  • Deposits usually start on Ethereum; withdrawal burns use Polygon PoS, and claims use Ethereum.
  • Polygon PoS is chain ID 137 (0x89); use Polygon’s official network details if you need to add it.
